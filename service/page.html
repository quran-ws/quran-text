Qurʾān text for developers

The Qurʾān, as a file your app can read.

Seven riwāyāt, letter for letter as the King Fahd Complex prints them. Choose the shape, copy the URL, done.

A riwāyah is one canonical reading of the Qurʾān; Ḥafṣ is the one in most printed copies. The King Fahd Complex (KFGQPC) is the reference printer, and its text is used here unchanged.

Take the muṣḥaf's own file.
Every word of one riwāyah with its āyah, page, line, juz and marks, in one flat JSON. Every format above is cut from it. An āyah is a slice, a page is a slice; no nesting, no ids to join.

import json m = json.load(open("hafs.json")) # sūrah 2, āyah 255 is a slice a = m["ayah_starts"] k = m["suras"][1]["first_ayah"] + 254 print(" ".join(m["words"][a[k]:a[k+1]])) # page 3 is a slice too p = m["page_starts"] page3 = m["words"][p[2]:p[3]]

the fonts

One font per riwāyah.
Ship it with the text.
Each text uses letters and signs that only its own KFGQPC font draws: the open tanwīn, the small alifs, the pause marks. In any other Arabic font some of them show as gaps or boxes. The fonts are KFGQPC's own, redistributed with the text.
